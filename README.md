## 🎮 About the Game

Fire Keeper is a 2D action roguelite prototype built around fast-paced combat, run-based upgrades and permanent unlockable gameplay styles.

Take control of a living cauldron and fight your way through a dungeon filled with candle and lantern enemies. Survive increasingly difficult encounters, collect Fire Fragments, defeat powerful bosses and unlock new cauldrons that fundamentally change how you play.

The project began as an attempt to capture the feeling of playing *Tower Fortress* by Nitrome, combined with inspiration from games such as *The Binding of Isaac* and *Hades*.

## ✨ Features

- **8 dungeon rooms** with progressively challenging encounters.
- **2 unique boss fights** with distinct attack patterns and mechanics.
- **7 playable cauldrons**, each with its own combat identity.
- **Run-based upgrade system** with different combinations and synergies.
- **Permanent progression** through Fire Fragment collection and cauldron unlocks.
- **Multiple enemy types**, including melee and ranged candles and lanterns.
- **Workshop** for purchasing and selecting cauldrons.
- **Run summaries** displaying performance and collected rewards.

## 🫕 Playable Cauldrons

| Cauldron | Playstyle |
|---|---|
| Hearth | Balanced standard melee combat |
| Spiky | Punishes enemies that hit you in melee |
| Ranged | Mouse-aimed projectile attacks |
| Teal | Sweeping fireball attacks |
| Shotgun | Powerful short-range burst attacks |
| Thinner | Additional dash charges |
| Broken | High damage with severely limited health |

The Hearth Cauldron is available from the beginning. The other six can be unlocked using Fire Fragments.

## 🕹️ Controls

| Input | Action |
|---|---|
| WASD | Movement |
| Mouse | Aim and attack |
| Q | Dash |
| R | Reload (Ranged and Shotgun cauldrons) |
| Pause button | Pause the game |

## 🔥 Gameplay Loop

1. Enter the dungeon and fight through enemy encounters.
2. Collect Fire Fragments and survive increasingly difficult waves.
3. Choose temporary upgrades after clearing rooms.
4. Defeat bosses and progress through the dungeon.
5. Earn rewards and unlock new cauldrons in the Workshop.
6. Start another run and experiment with a different playstyle.

## 🛠️ Built With

- **Engine:** Godot 4.7.2
- **Rendering:** Compatibility renderer
- **Language:** GDScript
- **Target:** Desktop and browser

## 🚀 Running the Project

1. Download or clone this repository.
2. Install [Godot 4.7.2](https://godotengine.org/download/).
3. Open Godot's Project Manager.
4. Select **Import** and locate the `project.godot` file in the downloaded project folder.
5. Open the project and press Play.

No additional plugins or external dependencies are required for the base project.

## 🎨 Development & AI Usage

Fire Keeper was designed and directed by me, with the initial enemy concepts, visual direction and gameplay ideas developed as part of the project.

As someone primarily experienced in game art and design rather than programming, I used generative AI tools, primarily ChatGPT, as a programming assistant to help implement gameplay systems, write and debug GDScript, and iterate on mechanics.

The design decisions, feature requirements, testing and final implementation choices were directed and reviewed throughout development.

AI was used as a development aid to help turn the original concepts into a playable prototype.

## 🎯 Project Goal

The goal of this project was to take an initial game concept and develop it into a functional, playable prototype, exploring combat, enemy behaviour, progression systems, player choice and replayability.
